SEU ANDROID, CONECTADO

Avisos que chegam até você.

Push independente do site. Com a tecnologia já usada no AMZX.

Ativar Web Push

NESTE APARELHO
1

Autorize este Android

Permita as notificações no Chrome ou no PWA instalado. Não use uma aba anônima.

2

Conecte ao seu GitHub

O cadastro gerado neste aparelho fica somente aqui até você copiá-lo para um Secret privado.

Abrir novo Secret ↗
Onde colar a configuração?
  1. No GitHub, use o nome AMZX_WEBPUSH_CONFIG.
  2. No campo Secret, cole a configuração copiada e salve.
  3. Se o Secret já existe, edite-o. Não crie um arquivo público com esse conteúdo.
  4. Execute o monitor e marque “Enviar teste de Web Push”.

Esta ativação cadastra um aparelho. Para manter vários, combine os objetos da lista devices no Secret (até cinco). Uma nova configuração substitui a anterior.

3

Teste a entrega e o som

O teste local verifica a notificação do navegador. O teste remoto confirma o caminho GitHub → push → aparelho.

Abrir teste remoto ↗
Aguardando ativação neste aparelho.

Para ouvir o alerta

Nas configurações do Android, permita som nas notificações do Chrome ou deste PWA e confira o volume. O modo Não Perturbe e a economia de bateria podem interferir. O push não força o aparelho a tocar.

Esse áudio é apenas um teste nesta tela; não é o toque da notificação com o app fechado.
